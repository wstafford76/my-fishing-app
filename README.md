# My Fishing Reference

Personal fishing guides and editable tackle inventory.

## Features
- Five fishing guides hosted in the preserved backup repository to keep the Pages deployment lightweight
- Searchable guide library
- Tackle inventory with box/compartment, soft-bait bags, line and leaders, and unassigned gear
- Add, edit, and delete inventory entries
- Local browser saving plus JSON export/import backup

Open `index.html` through GitHub Pages. Guide PDFs open from the backup repository, so they are not bundled into the Pages deployment. Inventory edits are stored in that browser/device; export a JSON backup before changing devices or clearing browser data.
